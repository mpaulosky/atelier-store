## PR description

### Summary
- Adds `tests/AtelierStore.Web.Tests.Bunit`, covering `ProductPrice`, `ProductCard`, `SiteHeader`, `ProductDetail`, and `Home` with bUnit component tests.
- Uses NSubstitute for `IProductCatalog` (no EF/database) and bUnit's `AddAuthorization()` for the signed-in/anonymous `SiteHeader` states.
- Registers the project in `AtelierStore.slnx` under `/tests/`.

### Scope covered
- `ProductPrice`: regular price vs. sale price (accent price, struck-through Was Price, `sr-only` text), `C0` en-US formatting.
- `ProductCard`: Sold Out replaces the Badge; Badge shown when in stock; no badge otherwise; link to `products/{slug}`.
- `SiteHeader`: "Log in" when anonymous, "Log out" when signed in.
- `ProductDetail`: stock labels ("In stock" / "Only N left" / "Sold out"), disabled "Sold out" button, no Badge when sold out (intentional per `CONTEXT.md`), `NotFound()` raised on an unknown slug, related products rendered as cards with `GetRelatedAsync(slug, 4)`.
- `Home`: one `ProductCard` per item from `GetNewArrivalsAsync(8)`.
