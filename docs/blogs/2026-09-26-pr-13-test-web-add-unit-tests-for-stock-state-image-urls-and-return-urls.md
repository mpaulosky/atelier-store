# test(Web): Add unit tests for stock state, image URLs and return URLs

- **Release tag:** `v0.0.4`
- **Source PR:** [#13](https://github.com/mpaulosky/atelier-store/pull/13)

## PR description

### Summary
- Adds `tests/AtelierStore.Web.Tests.Unit`, wired into `AtelierStore.slnx` under a `/tests/` folder.
- Covers `Catalog.Product.StockState` boundaries (-1, 0, 1, 3 = `LowStockThreshold`, 4), `UnsplashImage.Url`/`SrcSet`, and the `ReturnUrl.IsLocal` open-redirect guard via a `[Theory]` over `null`, `""`, `/`, `/products/x`, `//evil.com`, `/\evil.com`, `https://evil.com`, `products/x`, `/%2F%2Fevil.com`, plus two extra cases (`///evil.com`, `\evil.com`).
- 19 tests total, all passing.

### Break-it check
Each area was temporarily broken to confirm the tests actually catch a regression, then reverted (no production diffs remain):
- `StockState` switch: `<=` → `<` on both boundaries — the `stock: 0` and `stock: 3` cases went red as expected.
- `UnsplashImage.SrcSet`: join separator `", "` → `","` — the srcset-format test went red as expected.
- `ReturnUrl.IsLocal`: dropped the `'\\'` check — the `"/\evil.com"` theory case went red as expected.

### Notes
- `/%2F%2Fevil.com` is accepted (`IsLocal` returns `true`) by design: the guard only inspects the literal second character for `/` or `\`, and nothing downstream percent-decodes the path before using it as a redirect target, so this isn't an exploitable open redirect through this guard alone. Documented in a code comment on the test rather than filed as a bug.
