## What

- No new CSS, catalog methods, or migrations. Responsive layout comes from `.product-grid` (2 / 3 / 4 columns), checked at 375, 768, 1024, and 1440px.
- `src/AtelierStore.Web/CLAUDE.md` documents the listing-page pattern.
