_Requested by **Matthew** · [project thread](https://claude.ai/code/project/chan_01M4TRjuaTvMLM1jqeNd9KNs?thread=cmsg_01M4TRjuaTvMLM1jqeNd9KNsBqvSH7Zyjxovd4Kr4rap1i)_

Before: pnpm 12 wrote `src/AtelierStore.Web/pnpm-lock.yaml` as two YAML documents, with the pnpm version first. GitHub's dependency graph reads only that first document, so it saw no project dependencies and Dependabot security alerts could silently close ([dependabot/dependabot-core#15904](https://github.com/dependabot/dependabot-core/issues/15904), still open).

After: `pnpm-lock.yaml` is a plain single-document lockfile, so the dependency graph sees the Node dependencies again.

`pmOnFail: ignore` in `pnpm-workspace.yaml` makes pnpm stop writing the pnpm-version document. The regenerated lockfile is identical to the old second document; no versions change. The trade-off is that a local pnpm no longer switches itself to 12.6.0; CI still runs 12.6.0 because `pnpm/action-setup` reads `packageManager`. Same change as mpaulosky/Articles#274.

How: two files, `src/AtelierStore.Web/pnpm-workspace.yaml` (+6 lines, with a comment explaining why) and `src/AtelierStore.Web/pnpm-lock.yaml` (−158 lines).

Verified locally: `scripts/gate.sh` passed (lint, Release build, all test projects).
