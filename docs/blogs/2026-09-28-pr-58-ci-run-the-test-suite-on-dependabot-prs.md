## ci: Run the test suite on Dependabot PRs

- **Release tag:** `v0.0.24`
- **Source PR:** [#58](https://github.com/mpaulosky/atelier-store/pull/58)

### PR description

`ci.yml` skipped test discovery, every test job, coverage and the report job whenever Dependabot opened the PR. GitHub counts a skipped check as passing, so Dependabot bumps merged without a single test run (for example #11). None of these jobs needs a secret: the tests use fakes and Testcontainers. So they now run on Dependabot PRs too.

Dependabot runs always get a read-only `GITHUB_TOKEN`, so the step that publishes the "Test Results Summary" check run and PR comment still skips there. The report job's status step still fails the job when any test did.

**Follow-up after merge:** add `Test Report Summary` to the `main-rules` required checks. Currently no test result is required, so a PR with failing tests could still merge through native auto-merge. Dependabot PRs merge that way.

Validation: `actionlint`, `zizmor` and `yamllint` are clean, and the pre-push gate passed.
