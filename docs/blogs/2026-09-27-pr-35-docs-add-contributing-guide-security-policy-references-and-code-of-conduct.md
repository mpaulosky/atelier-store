### PR description

## Summary

Adds the four community health files under `docs/`, where GitHub picks them up for the repository's community profile. They describe this repository; nothing is left over from other projects.

- **`CONTRIBUTING.md`:** local setup, the project layout, branch naming (the patterns the pre-push hook accepts), the commit format, code style, how to add EF Core migrations, which of the four test projects to use, what the git hooks check, and how pull requests are reviewed and auto-merged.
- **`SECURITY.md`:** supported versions (the latest `v0.0.x` release), how to report a vulnerability (GitHub private vulnerability reporting first, email second), response and disclosure commitments, and only the protections the app and repo actually have: Auth0 OIDC, the return URL check, HTTPS and HSTS, anti-forgery, `.env` secrets, secret scanning with push protection, Dependabot, CodeQL, and pinned actions. It also lists the known gaps: no security headers, no rate limiting, a GET logout, a public `/health`, and no audit logging.
- **`REFERENCES.md`:** the libraries, tools, and services in use, grouped by area. It points to `Directory.Packages.props` for exact versions so it doesn't go stale as Dependabot updates them.
- **`CODE_OF_CONDUCT.md`:** Contributor Covenant 2.0.
