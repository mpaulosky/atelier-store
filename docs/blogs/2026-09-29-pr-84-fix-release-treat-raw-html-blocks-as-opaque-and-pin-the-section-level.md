### How

- **HTML blocks:** `html_block_end()` recognises CommonMark's seven kinds of HTML block, each with its own end condition. Kinds 1–5 (`<pre>`/`<script>`/`<style>`/`<textarea>`, comments, `<?`, `<!X`, CDATA) end on their closing marker, possibly on the same line. Kinds 6 and 7 (block tags like `details`/`div`, and any other complete tag alone on a line) end at a blank line.
- **Interruption:** kind 7 can't interrupt a paragraph. But a line that fails to continue its quote or list item can open any kind, as GitHub renders it. This is the same rule as for list items.
- **Scanner:** the old `comment` flag became a general `html_end` condition, so HTML comments are simply kind 2.
- **Excerpts:** `code_lines()` and `first_paragraph()` now skip HTML block lines, so a `<details>` block's tags never become the blog-card excerpt.
