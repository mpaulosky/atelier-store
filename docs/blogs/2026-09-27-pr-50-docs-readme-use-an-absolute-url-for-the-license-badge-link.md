## Summary

Resolves the Copilot review finding on #48 ([discussion_r4116679219](https://github.com/mpaulosky/atelier-store/pull/48#discussion_r4116679219)).

`docs/README.md` is a verbatim copy of the root README (made by `sync-readme.yml` and by `release_post.py`), so the relative `(LICENSE)` link resolved to `docs/LICENSE`, which doesn't exist. Switching the badge to an absolute URL, like every other link in the badge block, makes it work from both locations. Rewriting links inside the copy steps would have fixed only one of the two copy paths each time.
