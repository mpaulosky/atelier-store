# test(release): Track only column-zero fences in heading_levels()

- **Release tag:** `v0.0.33`
- **Source PR:** [#81](https://github.com/mpaulosky/atelier-store/pull/81)

## PR description

Closes #80

### What

Follow-up to #77, fixing the Copilot thread left open when it merged. `heading_levels()` is the test helper behind the "one H1, no skipped levels" invariant tests. It deliberately over-counts headings so it can never miss one, but it treated an *indented* fence or comment opener as top-level. An opener indented under a list item belongs to that item and ends with it. For `- item`, an indented fence, then `# Root`, the helper stayed in fence state and missed the root H1.

The helper now tracks only fence and comment openers at column 0, which are unambiguously top-level. Closing fences keep the 0–3-space match. This is a test-only change; `release_post.py` is untouched.

### Tests

- Two new cases in `test_heading_levels_counts_every_heading_looking_line`: an indented fence and an indented comment under a list item, each followed by `# Root`. The helper on `main` returns `[1]` for both (missing the root H1), and this one returns `[1, 1]`.
- 124 of 124 Python tests pass. The pre-push gate passes.
