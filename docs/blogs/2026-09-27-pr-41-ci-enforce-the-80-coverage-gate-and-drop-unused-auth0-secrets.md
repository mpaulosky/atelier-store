## ci: Enforce the 80% coverage gate and drop unused Auth0 secrets

- **Release tag:** `v0.0.17`
- **Source PR:** [#41](https://github.com/mpaulosky/atelier-store/pull/41)

### PR description

Closes #8 (slice 6 of 6 of the test work).

## Changes

- **Remove `Auth0__*` secrets from the CI test step.** The integration and E2E fixtures override every `Auth0__*` setting with fakes and swap in a fake auth scheme, so tests never read the secrets.
- **Make the 80% coverage gate fail CI.** The Coverage Analysis job now errors when line coverage is below 80%, and also when `Summary.json` is missing or has no coverable lines (previously both silently skipped the gate). The job only runs when test projects exist, so a missing report means something broke. Latest `main` coverage is 98.7%.
- **Update `CLAUDE.md`.** Replace the "no test project" note (and the stale "holds one project" line) with a **Tests** section describing the four test projects, their prerequisites, test isolation from Auth0 and the dev database, and how CI and `scripts/gate.sh` run them. Adds a `dotnet test --project` example to Commands.

## Note

`main-rules` requires only **Build Solution**, so a failing Coverage Analysis job turns CI red but does not block merge. Adding it as a required check is a separate ruleset change.
