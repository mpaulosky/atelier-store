### PR description

README sync PRs could never merge. `sync-readme.yml` committed with the skip-CI marker in the message, and GitHub skips every workflow when the head commit carries it. So `main`'s required checks never reported on the sync PR.

The fix drops the marker from the commit message. The PR's `[skip-release]` title still keeps the sync from producing a release.

Same fix as mpaulosky/Blazor-Server#110 and the TicketManager PR. `actionlint`, `zizmor` and `yamllint` are clean, and the pre-push gate passed.
