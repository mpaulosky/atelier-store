### Why

The Template has changed since #103. This re-Apply brings atelier-store up to date, after TicketManager as the live check (mpaulosky/TicketManager#116).

### What changed

**Apply** (`chore: Apply repo-ci-baseline Template`, the script's output alone; 11 Owned files added, 25 overwritten):
- **One written PR process:** `docs/PROCESS.md`, a PR template, and a **PR title** check (`pr-title.yml`, `check-pr-title.sh`).
- **Branch names are checked in CI** as well as in `pre-push` (`check-branch-name.sh`).
- **Worktrees:** `pre-commit` refuses commits in the main checkout; every change goes in a worktree under `../atelier-store-worktrees/`.
- **Auto-merge:** a 3-round cap on Copilot's reviews, the `sandcastle:needs-human` hand-back, and a re-check when a review is submitted (`pr-review-submitted.yml`).
- **Releases:** Dependabot bumps fold into the next Release; the CI summary names a docs-only skip.
- **The pre-push gate tests what CI's discovery finds** (`discover_tests.py --list`).
- **Smaller changes:** `.gitignore` additions, `load_test_env.py`, the release and backfill fixes, and the `codecov.yml` and lint config updates.

**Adapt:**
- `CLAUDE.md` and `docs/CONTRIBUTING.md` point at `docs/PROCESS.md` for branches, commits, PRs, review, merging and releases. The repo's commit scopes stay.
- `dependabot.yml`: the `chore(deps)` commit prefix for all four ecosystems.

**GitHub settings** (`github-settings.sh --fix`, first pass, already applied):
- squash only, with PR title + body as the commit;
- pinned actions required;
- `code_quality` rule removed; `markdownlint` and `yamllint` now required;
- `docs-only` and `sandcastle:needs-human` labels created.

The second pass, right after this merges, adds **Branch name** and **PR title** to the required checks.
