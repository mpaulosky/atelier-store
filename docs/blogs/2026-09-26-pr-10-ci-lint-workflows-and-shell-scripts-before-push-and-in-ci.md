# ci: Lint workflows and shell scripts before push and in CI

- **Release tag:** `v0.0.2`
- **Source PR:** [#10](https://github.com/mpaulosky/atelier-store/pull/10)

## PR description

### Summary

PR #2 passed every CI check but still drew ~27 review findings, almost all in workflows and hooks: shell injection in `run:` blocks, over-broad permissions, an action pinned to `@main`, unquoted shell. No existing gate looked at workflow semantics. This adds tools that do, locally and in CI.

**New checks**
- `scripts/gate.sh` (pre-push) runs **actionlint** and **zizmor** when a workflow, `dependabot.yml` or their configs change, and **shellcheck** when a shell script or git hook changes. Each uses an installed tool first. Otherwise it falls back to a pinned version via `uvx` or Docker. If neither is available, it warns and skips.
- New **Lint Actions** workflow runs the same tools at the same versions. zizmor fails on medium severity and above. `pr-automerge` re-checks when it completes.
- **CodeQL** also analyzes the `actions` language, and runs on pushes to `main` that change workflows.

**Hardening the tools asked for**
- Every action is pinned to a commit SHA, with a version comment that Dependabot keeps current. Dependabot gets a 7-day cooldown.
- The `release.yml` Summary step no longer inserts step outputs into shell (template injection).
- `ci.yml`'s job summary is rewritten with quoting and `env:` values.
- Checkouts that never push set `persist-credentials: false`. The four jobs that push keep their credentials, marked with a documented zizmor ignore.
- The deliberate `pull_request_target` triggers in `pr-automerge` and `dependabot-auto-merge` are marked with a documented ignore. Neither checks out PR code.
- Two shellcheck warnings are fixed.

**Also in this PR: use pnpm instead of npm** (`d497ffb`)
- The `gate.sh` markdownlint fallback, the pre-commit hint and the hook-test stubs switch from npm/npx to pnpm.
- `package.json` `engines.npm` plus `.npmrc` `engine-strict` make an accidental `npm install` fail.
- Release posts skip `pnpm-lock.yaml` along with `package-lock.json`.
- README and `CLAUDE.md` document pnpm as the only package manager.

**Copilot review fixes** (`c6c7009`)
- CodeQL's `actions` detector matches `.yaml` workflows as well as `.yml`.
- The pre-push hook tests stub actionlint, zizmor and shellcheck. They check that each runs only when its files change and that a failure from any of them refuses the push (35 tests, 15 new). Each deliberately broken copy of `gate.sh` fails at least one test.

### Needs a repository setting

Add **actionlint**, **zizmor** and **shellcheck** as required checks in the `main` ruleset. Until then, a human can merge past a failure. Auto-merge still waits for the checks, because it requires a clean merge state.
