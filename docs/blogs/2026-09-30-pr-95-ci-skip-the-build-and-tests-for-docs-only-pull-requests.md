# ci: Skip the build and tests for docs-only pull requests

- **Release tag:** `v0.0.39`
- **Source PR:** [#95](https://github.com/mpaulosky/atelier-store/pull/95)

## PR description

### Summary

Part 3 of #86, porting mpaulosky/IssueTracker#175. Release blog PRs change only `docs/` and Markdown, yet each one ran the whole build and test matrix before it could merge.

- **`Detect Changes` job:** on a pull request it runs `.github/scripts/detect_changes.py`, which lists the changed files (`git diff --name-only --no-renames -z` against the base). The PR is docs-only when every path is under `docs/` or ends in `.md`. Everything else counts as code: workflows, scripts, project files, and an empty diff. Pushes and manual runs always build. `--no-renames` lists a rename under both paths, so moving code into `docs/` still builds.
- **`Build Solution`** needs `changes` and runs only for code. Test discovery, the test matrix and coverage skip through their `needs` chains. A job skipped by its own `if:` still reports, and a skipped required check counts as passing, so the PR still merges.
- **`Test Report Summary`** (required) needs `changes` too, and fails when detection didn't succeed, so a broken detection can't skip the build *and* pass. Its summary notes a docs-only skip.
- **CodeQL** ignores docs-only PRs (`paths-ignore: docs/**, **/*.md`). It isn't a required check, and its push and weekly runs still cover `main`.

Lint, Python and hook tests still run on every PR.

### Testing

- New `test_detect_changes.py` (22 tests) builds real git repos: docs-only, code, mixed, an empty diff, code moved into `docs/`, code renamed to `.md`, a deletion, and file names with spaces and newlines, plus how each path is classified and the output the job reads. All script tests: 192 passed.
- `yamllint`, `actionlint` and `zizmor` are clean, and the pre-push gate passed.
- **Live, before merging:** a throwaway draft PR that changes one doc, targeting this branch, ran the new `ci.yml` (then with the rule inline in the workflow) against a docs-only diff (#96, closed unmerged): `Detect Changes` passed; `Build Solution`, `Discover Test Projects`, the test matrix and `Coverage Analysis` were skipped; `Test Report Summary` passed; CodeQL didn't run.
- **Live, after merging:** this PR's own blog PR is docs-only, so it must merge under `main`'s ruleset with `Build Solution` skipped.
