## PR description

Slice 1 of 6 of the test plan. Closes #3.

### Changes

- **MTP opt-in**: `global.json` sets `"test": { "runner": "Microsoft.Testing.Platform" }`. The `dotnet test --report-xunit-trx --coverage` switches in `ci.yml` need it.
- **`tests/Directory.Build.props`**: xUnit v3 (4.x, MTP v2), FluentAssertions 8, NSubstitute + analyzers, and `Microsoft.Testing.Extensions.CodeCoverage`, plus global usings.
- **`Directory.Packages.props`**: versions for the test packages (bUnit, Mvc.Testing, Testcontainers.PostgreSql, Respawn, Playwright as well).
- **`IProductCatalog`**: pages inject the interface, and `ProductCatalog` implements it (still a singleton).
- **`Account/ReturnUrl.IsLocal`**: the open-redirect guard moved out of `Program.cs` unchanged, `internal`, with `InternalsVisibleTo` the Unit project.
- **Instructions**: the test filter syntax is updated for MTP (`--filter-class` / `--filter-method`).
- **`CONTEXT.md`**: domain glossary (the commit before this one).

The test projects aren't added here, because MTP fails a run that finds zero tests. Each slice adds its own project.
