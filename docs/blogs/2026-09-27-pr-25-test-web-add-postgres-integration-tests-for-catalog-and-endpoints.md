## test(Web): Add Postgres integration tests for catalog and endpoints

- **Release tag:** `v0.0.12`

### PR description

## Summary

- Adds `tests/AtelierStore.Web.Tests.Integration`: a Testcontainers `postgres:17` fixture, one container per assembly, real `Database.MigrateAsync()` schema, Respawn reset between tests, per-test data via builders.
- `ProductCatalog` against real Postgres: case-insensitive slug lookup, unknown slug, missing stock row reads as 0, related products (excludes self / same category first / then newest / honours count), new arrivals (newest first / honours count).
- Check constraints from the `InitialCatalog` migration: negative price, `was_price <= price`, negative stock quantity all throw `DbUpdateException`.
- A dedicated seed test asserting what the migration's `HasData` actually inserts, read from a snapshot captured before any Respawn reset.
- `WebApplicationFactory<Program>` with Auth0 fully faked (fixed OIDC configuration, `TestAuthHandler`): `/health` → 200, `/account/login` preserves a local `returnUrl` and sanitises off-site/malformed ones to `/`, `/account/logout` signs out and redirects towards the fake tenant without ever calling it.
- Confirms and documents (`// BUG: #16`) that `ProductCatalog.FindBySlugAsync` can never find a product whose stored slug has mixed case; filed as #16.

Closes #6
