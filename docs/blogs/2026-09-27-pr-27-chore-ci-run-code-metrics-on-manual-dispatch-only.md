## chore(ci): Run code metrics on manual dispatch only

- **Release tag:** `v0.0.11`
- **Source PR:** [#27](https://github.com/mpaulosky/atelier-store/pull/27)

### PR description

## Summary

- Removes the `push` and `pull_request` triggers from `.github/workflows/code-metrics.yml`. The workflow can still be run by hand through `workflow_dispatch`.
- Adds a comment explaining why the triggers were removed and when to restore them.

## Why

The pinned `dotnet/samples` metrics action does not count the members of classes declared with a primary constructor. In #24 it reported 13 types as having 0 members: `ProductCatalog`, `AppDbContext`, `AtelierAppFactory`, `PlaywrightTestBase`, `TestAuthHandler`, and all 8 E2E scenario classes. Every one of them uses a primary constructor, and the repo's code style uses them throughout, so the generated report would stay wrong for most new code too.

#24 is closed. Restore the triggers once the upstream action handles primary constructors.
